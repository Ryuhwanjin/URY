# URY v0.9.4 User Guide

macOS·Windows 공통 사용 설명서
Designed & Built by Ryu.H.J

## MUST READ — 최초 설정 순서

1. Google AI Studio(<https://aistudio.google.com/app/apikey>)에서 **Get API key → Create API key**로 키를 발급합니다.
2. URY의 **Settings → Gemini Key**에 붙여넣고 **설정 저장**을 누릅니다. 키는 로그·스크린샷·Git에 남기지 마세요.
   별도 프로젝트의 키가 있다면 **Backup Key**에도 등록할 수 있으며, 기본 키에서 429/503이 발생할 때만 자동 사용됩니다.
3. Settings에서 수강 학기를 고르고 과목, 전담 튜터 이름, 강의계획서를 등록합니다.
4. 저장하면 다음 구조가 만들어집니다.

```
~/Desktop/URY/
└── <학기>/<과목>/
    ├── 음성녹음  강의자료  강의노트  예상문제  과제  강의계획서
```

API Key와 설정은 `workspace/system/settings.json`, `.env`에 저장됩니다. 새 URY 앱과 이전 버전이 같은
`~/Desktop/URY`를 읽습니다. 앱 버전별 데이터는
자동 분리되지 않으며, 학기 폴더만 분리됩니다. 반드시 현재 학기와 과목을 확인한 뒤 자료를 선택하세요.

## Studio

- Step 1에서 학기·과목·수업 일자·주차·차시·Part(1부/2부/3부)를 선택합니다.
- Output language는 Settings의 과목별 언어 모드(한국어·영어·한/영 동시)와 연동됩니다.
- **실시간 마이크 녹음**으로 녹음하거나 기존 m4a/mp3/wav 파일을 연결합니다. 종료하면 날짜·과목이 포함된 이름으로 저장됩니다.
- **강의자료 선택**은 현재 과목의 강의자료 폴더를 열며 PDF/PPTX/이미지를 복수 선택합니다. 체크박스로 포함 파일을 확인하고 전체 선택/해제할 수 있습니다.
- 칠판 사진을 추가하거나 음성 없이 슬라이드 집중 분석 모드를 사용할 수 있습니다.
- **강의노트 생성**은 선택한 입력만 분석해 Markdown·PDF를 만들고, 진행 단계·모델·수신 글자 수를 화면과 로그에 표시합니다. 완료 후 PDF 열기/폴더 열기를 사용합니다.

## Quiz & Exam

- 대상 과목, D-Day, 시험 종류, 문항 수, 문제 유형, 일일 공부 시간을 설정합니다.
- **강의노트 폴더** 또는 목록에서 출제 범위 자료를 복수 선택합니다. 선택하지 않은 과목 자료는 전송하지 않습니다.
- **모의시험 PDF**는 문제지와 정답·해설을 생성합니다.
- **학습 로드맵 생성**은 시험일까지의 주차별 계획을, **벼락치기 정리노트**는 핵심 요약을 만듭니다.
- **마스터 바이블**은 현재 과목의 강의노트를 통합합니다. 문제 폴더/시험지 열기로 결과를 확인합니다.
- 답안 채점 기능은 제공하지 않습니다.

## Tutor

- 과목을 선택하면 해당 학기·과목의 노트·자료·강의계획서로 대화가 분리됩니다.
- 질문 전송(Enter)과 자료 첨부를 사용할 수 있습니다.
- 답변 아래 실제 참조 파일명과 가능한 페이지가 표시됩니다. 자료 밖 일반지식은 구분됩니다.
- 강의계획서는 PDF/HTML/DOCX/MD를 복수 등록·삭제할 수 있습니다.
- 닉네임 변경, 자료 폴더 열기, 현재 과목 대화 초기화를 지원합니다.

## Settings

- 학기 드롭다운을 바꾸면 해당 학기의 과목·기간·튜터 대화·캐시가 전환됩니다.
- Gemini Key와 선택적 Backup Key를 저장하고 과목 추가·수정·삭제, 튜터 닉네임, 강의계획서, 폴더명, 차시 수, 언어 모드를 관리합니다. Backup Key는 별도 프로젝트에서 발급하고, 기본 키의 429/503 장애 시에만 사용됩니다. `연결 확인`으로 저장된 두 키의 인증 상태를 즉시 다시 확인할 수 있습니다.
- 대학 테마 또는 HEX 색상을 선택하면 주요 UI·창·Dock 아이콘 포인트 색에 적용되고 선택값은 자동 저장됩니다.
- 화면 해상도와 창 크기 기억 옵션을 설정할 수 있습니다.
- Finder의 앱 번들 아이콘은 정적 리소스이므로 테마 저장만으로 영구 교체되지 않습니다.
